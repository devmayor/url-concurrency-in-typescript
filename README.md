# URL Concurrency in TypeScript

This repository contains programming assignments focused on asynchronous programming and concurrency in TypeScript. The assignments are designed to help you understand and implement various asynchronous patterns and techniques in TypeScript.

## How to Use

### Prerequisites

- Node.js (version 14 or higher)
- npm (version 6 or higher)

### Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/devmayor/url-concurrency-in-typescript.git
    cd url-concurrency-in-typescript
    ```

2. Install the dependencies:

    ```bash
    npm install
    ```

### Running the Assignments

Each assignment is located in its own file. You can run the assignments using Node.js. For example, to run the `Asynchronous_programming.md` assignment:

```bash
node Asynchronous_programming.md
```
